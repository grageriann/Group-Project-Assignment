Front-End Developer

Reference Number: FE123

We are looking for a Front-End Developer to build responsive and accessible client websites. This role focuses on translating visual concepts into functional webpages using HTML5 and CSS3.

Position Summary

Salary: $68,000 – $80,000 per year

Reports to: Lead Developer

Key Responsibilities

  1. Develop responsive and user-friendly website layouts.
  2. Implement accessible HTML5 and CSS3 solutions for client projects.
  3. Work with designers to translate wireframes into polished interfaces.
  4. Test webpages across browsers and screen sizes.
  5. Maintain code quality and follow project timelines.

Essential Requirements

  • Strong knowledge of HTML5 and CSS3.
  • Understanding of responsive web design principles.
  • Ability to create accessible and semantic web content.
  • Good communication and teamwork skills.

Preferable Requirements

  • Experience with UI prototyping tools.
  • Knowledge of branding and visual consistency.
  • Previous project or portfolio experience.

Web Designer

Reference Number: WD245

We are seeking a creative Web Designer to produce visually engaging and client-focused website designs. This role involves layout planning, visual styling, and contributing to brand identity across digital platforms.

Position Summary

Salary: $65,000 – $76,000 per year

Reports to: Creative Director

Key Responsibilities

  1. Create web page layouts that reflect client branding.
  2. Design digital assets for websites and campaign materials.
  3. Work collaboratively with developers and content designers.
  4. Apply usability and accessibility principles to design decisions.
  5. Support revisions based on client and team feedback.

Essential Requirements

  • Strong visual design and layout skills.
  • Understanding of colour, typography, and user experience.
  • Ability to communicate design ideas clearly.
  • Attention to detail and consistency.

Preferable Requirements

  • Experience using Figma, Adobe XD, or similar tools.
  • Basic knowledge of HTML and CSS.
  • Portfolio demonstrating creative digital work.
